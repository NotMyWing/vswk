# Vintage Knuckle

[White Knuckle](https://store.steampowered.com/app/3195790/White_Knuckle/)-style climbing for Vintage Story 1.22.7.

Free up a hand and press **V** to climb. Works with support beams and windmills! Go ham.

## Build

Set `VINTAGE_STORY` to your game install and build with the .NET 10.0.4xx SDK or newer.

```sh
dotnet build -c Release
```
